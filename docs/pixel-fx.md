# 互动像素版（实验）

这是屏幕基础版之上的**第三种界面变体**，和歌词播放器互不依赖：

| 变体 | 目录 | 额外依赖 | 输出 |
| --- | --- | --- | --- |
| 基础屏幕版 | `firmware/ips/native_ui*.c` | 无 | `build/ips/` |
| 歌词播放器 | `firmware/ips-lyrics/` | `FONT.BIN` + Windows 后台 | `build/ips-lyrics/` |
| **互动像素版** | `firmware/ips/native_ui_reactive.c` | 一份方案背景 GIF | `build/ips-fx/` |

互动像素版不需要字库、不需要电脑后台，只上传一张 320×172 的 GIF 到 S1 槽位，再刷一次屏幕固件。

## 它怎么“互动”

固件里有四个情绪帧，靠键盘原生事件切换，不需要电脑监听：

| 帧 | 触发条件 | 画面 |
| --- | --- | --- |
| 0 平静 | 默认 | 上传的 GIF 本身（完整场景） |
| 1 Caps | CapsLock 打开 | 贴纸层换成大写态：颜色加深、灯亮起、项圈变色等 |
| 2 互动 | 最近 0.7–1.3 秒内按过键，或正在充电（方案可选） | 角色抬头、睁眼、脸红、火焰变大、霓虹更亮 |
| 3 待机 | 连续 15–30 秒没有按键（按方案设定） | 闭眼、打盹、灯火变暗、Zzz |

每次按键还会在方案的指定区域生成 2–12 颗粒子：花瓣、雪、雨、星火、纸屑、气泡、余烬、萤火、音符、爱心等。粒子有方向、重力、寿命、边界行为（消失/环绕/反弹）和形状（方块/加号/叉/菱形）。此外可以给一个贴纸层设置“呼吸”脉冲（心跳、灯光起伏）。

四个帧和粒子参数全部在方案（schema `rainy75-px/2`）里定义，固件只是解释这些数字；同一份固件源码可以为 50 套不同方案编译出不同固件。

v2.1/v2.2 还增加了三类可选能力：**角色动作**（逐帧循环 + 按键位移）、**按键面板**（左侧大键帽显示上一个按键）、**顶部状态栏**（左电量+百分比、右 CapsLock 徽标，支持双击校准）。它们都是按需编译：方案里不写就完全不占空间。功能与验证状态汇总见 [功能支持清单](features.md)。

## 角色真的会动（motion，v2.1）

除了粒子，贴纸层还可以带一整套逐帧动作：`px6-cat-run` 示范里，橘猫平时坐着、Caps 时竖尾警觉，**按键时用 6 帧跑步动画沿地板跑过去**（腿和身体一起动、越打越快、最多跑 200px），停下来又坐回去——全程零粒子。同一机制也能做车窗外掠过的灯、横向推进的波浪、扇翅膀的小鸟、跳动的火焰。示例源码见 `tools/schemes/px6_motion_demo.py`，格式见 [方案格式](pixel-scheme-format.md#角色动作motionv21)。

| 浪漫心动 | 9 | 心动、温柔 | 樱花告白、情书、摩天轮、萤火 |
| 幻想冒险 | 9 | 勇气、陪伴 | 像素幼龙、太空、街机、魔法师 |

其中「深夜咖啡」「像素幼龙」是源码库里的参考样例（`tools/schemes/px6_example.py`），其余 48 套由六个方案脚本生成（含深夜家族的 `px6_night.py`）。全部方案的源码、调色板、故事文案与互动参数都在仓库里，运行 `tools/scheme_gallery.py` 可以重新生成总览图与离线网页。

另有 `tools/schemes/px6_motion_demo.py` 生成零粒子的动作演示 `px6-cat-run`；个人角色的按键面板/顶栏方案放在 `local/whale/`，属于本地素材，不随源码发布。

## 构建与安装

```sh
# 1. 生成方案（也可只挑一套）
python tools/schemes/px6_example.py
python tools/verify_schemes.py --glob 'px6-*' --dir build/design-gallery

# 2. 用某一套方案构建屏幕固件（需要本机原厂输入与 clang）
python tools/build.py ips --stock inputs/ips-stock.bin \
  --pixel build/design-gallery/px6-warm-coffee --fx \
  --clang "/path/to/clang" --out build/ips-fx

# 3. 上传素材与烧录
python tools/serve.py
# 浏览器打开 http://127.0.0.1:8765/web/
# 先连接键盘 →「更换缓存动画」上传 build/ips-fx/ips/background.gif（确认覆盖 S1）
# 再「烧录」选择 build/ips-fx/ips/rainy75v2-ips.bin + manifest.json
```

固件与素材必须来自**同一次构建**：背景 GIF 是平静帧，贴纸和粒子由固件绘制，混用不同方案的 GIF 会出现贴纸位置与底色不匹配。

## 内存与资源边界

- 新增代码仍只占用屏幕固件的追加区 `0x0807EC90..0x08080000`（4960 字节），模块状态 `0x2005F000..0x20060000`（4 KiB）。
- 贴纸掩码以 PackBits 压缩存放在固件里，启动时解压到模块 RAM（每套方案 ≤2560 字节）；压缩后 ≤1200 字节。
- 粒子最多 24 个，每帧最多 4 个 52 字节级操作以外的开销可忽略；不在按键/UART 回调里做文件 I/O。
- 所有方案都会在构建矩阵里检查 `.text+.rodata ≤ 4976`、`.data = 0`、`.bss ≤ 4096`。

- 预览图、按键动画 GIF 与网页都由同一份方案源码渲染，属于**软件预览**。

- 50 套方案的预览、掩码往返、帧差与预算检查都由 `tools/verify_schemes.py` / `tools/build_matrix.py` 在主机上完成，属于**模型检查**。

## 已知限制

- 每套方案只有 4 个情绪帧，切换是整块贴纸替换，没有逐像素动画（逐帧动画仍可由上传 GIF 提供）。
- 粒子是方案级参数，不是脚本化动画；同一时刻风格统一，不能做复杂剧情。
- 屏幕右上角状态区（连接图标/电量/百分比）保留，方案不能遮挡它。
- 只支持 `docs/build.md` 列出的原厂输入版本；不改变按键扫描、无线固件或输入延迟。
